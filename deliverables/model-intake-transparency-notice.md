# Draft transparency notice for live analysis

**Run screen and command line help**

> You are using an AI-assisted research tool. In live mode, an AI model analyses public documents about the model you select. Enter only a public model identifier and, if needed, its provider. Keep names, private identifiers and confidential details out of these fields.

Show this notice when the live analysis view opens, before input or submission. Include it in command-line help and display it before a live command sends any data.

**Report header and full Markdown export**

> This brief contains AI-generated findings based on public sources. Check the cited passages and exact model version before relying on a finding. A missing result means this run found no sufficient evidence. It cannot establish whether the supplier has the information.

Show the report notice before the first finding. Carry it into shared copies of live-generated reports. Label saved live reports by how they were produced and label offline previews as sample data. Present the notice as accessible text. The provider must separately implement and test machine-readable marking and detection wherever Article 50(2) applies.
