## How to complete this lab

1. **Fork** this repository.
2. Do the work described in `instructions.md`, committing to your fork.
3. Open a **pull request** back into this repository.
4. You'll receive **AI feedback** on your PR based on `rubric.md`. Address any blocking feedback and push updates to the same PR.

## Submission hygiene

- Keep this repository scoped to this lab only — no unrelated projects or personal files.
- Use clear, descriptive filenames.
- Remove secrets, API keys, and tokens before committing.

## Student submission — Intellectus

This submission audits **Intellectus — Social Impact Intelligence**, the Project 3 system built to support evidence-based, consultant-reviewed diagnostics for social-impact organizations.

### Submission files

- [`intellectus-system-brief.md`](./intellectus-system-brief.md) — plain-language description of the system, its inputs, outputs, affected people, human review process, builders and intended users.
- [`intellectus-eu-ai-act-assessment.md`](./intellectus-eu-ai-act-assessment.md) — first-pass EU AI Act classification, role map, applicable obligations, gap analysis, remediation plan and reassessment triggers.
- [`intellectus-compliance-memo.md`](./intellectus-compliance-memo.md) — one-page compliance memo for a fictional Head of Product, summarising classification, roles, key findings and recommended next steps.
- [`intellectus-human-oversight-procedure.md`](./intellectus-human-oversight-procedure.md) — Stretch artifact defining the human-review process required before a diagnostic is treated as client-ready.

### Assessment boundary

The audit covers the intended Intellectus production model: the research and evidence layer, diagnostic and transformation workflows, web application, n8n orchestration, response validation and consultant-reviewed final brief.

The assessment distinguishes between controls already demonstrated in the prototype, controls that are only partially implemented, and additional measures required before production.

This is an educational first-pass assessment. It is not legal advice, a conformity assessment, certification or guarantee of compliance.
